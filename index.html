Automate your CI/CD with GitHub Actions

Build, test, and deploy your code directly from your GitHub repository. Create powerful workflows that automate your development lifecycle.

Get Started

Example Workflow

name: CI Pipeline

on: push

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Install
        run: npm install

      - name: Test
        run: npm test
